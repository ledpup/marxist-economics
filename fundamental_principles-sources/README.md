# Sources quoted in the *Fundamental Principles*

Who the Group of International Communists (GIC) quotes in *[Fundamental Principles of Communist Production and Distribution](../Documents/fundamental_principles/README.md)*, and where. The book was written collectively by the GIC (first draft by Jan Appel, edited by Henk Canne Meijer), published in German in 1930, and revised for the Dutch second edition of 1935. The English text in this repository is Hermann Lueer's 2020 translation.

Each author has a file with a short biography (from Wikipedia, linked), a table of the works the GIC cites with their original publication dates, and a table of every quotation with links to its place in this book and to the original text online where one exists. Marx and Engels share one file, with a **By** column saying which of them wrote each work.

The book contains 125 quotations: from 22 authors (two of them pairs: Marx and Engels, Larin and Kritsman) and from a number of congresses and periodicals.

## Method and caveats

- Quotes were collected from the chapter files: block quotes, `»…«` guillemets, and inline quoted phrases with a source. Statistics tables, the Appendix's chronology, and quotation marks used only for irony are left out.
- Pages and editions are those the GIC (or the editor) cites; they are not checked against the originals unless a note says so.
- Publication dates are first publication in the original language. Where the book's date differs, the note says so.
- “Original” links go to the Marxists Internet Archive or another free copy. Each Marx, Engels, Lenin and Hilferding link was checked to contain the quoted passage, except where a note says otherwise.
- Biographies summarise the lead of each person's Wikipedia article (read October 2026). Where there is no article, the note says so and links another source.
- These files are generated by [generate.py](generate.py), which holds all the data. Edit the data there and run `python fundamental_principles-sources/generate.py` rather than editing the tables by hand.
